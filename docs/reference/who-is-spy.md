# PiTavern「谁是卧底」群聊文字局规则

> 版本：v1.35（正式稿，四方评审中）
> 属主：PM | 分支：docs/who-is-spy | 状态：讨论收敛中，未生效
> 用途：PiTavern 在线 Character 群聊内可直接游玩的文字推理局。

## 1. 概述

「谁是卧底」是多人推理发言游戏：多数玩家获得**平民词**，少数玩家获得**卧底词**（与平民词相近但不同的词）。玩家轮流用一句话描述自己手中的词（**不得直接说出**），通过发言盘问与投票找出卧底。

PiTavern 版适配原则：**流程走群聊公屏，身份与投票走私聊**——利用四方独立 session 的天然信息隔离，零代码改动即可开玩。

## 2. 参与方

| 角色 | 人数 | 说明 |
| --- | --- | --- |
| 主持人（裁判） | 1 | **v1 固定由 User Persona（苍蓝星）担任**——角色间无私聊通道，只有苍蓝星持有与所有玩家的私有通道（User↔Character 私聊），可私发身份/收票。轮值主持 = 未来增强，依赖 PiTavern 新增角色间私信能力（协议变更，按契约零漂移需四方另行确认），**v1 明确不做** |
| 玩家 | 3–6 | 在线 Character（如 Arch / Dev / PM / QA）。当前四方 4 人局即可开玩；掉线降级 3 人局（1 卧 2 民）仍可玩 |

## 3. 身份与词对

- **词对**：一组相近词（平民词 X / 卧底词 Y），如 周一/周日。每局由主持人从词库（§11）选取；多名卧底时共用同一组词对。
- **身份**：
  - 平民：持有 X
  - 卧底：持有 Y。人数：**3 人局 = 1 名；4 人局 = 1 名；5–6 人局 = 1–2 名**（开局前主持人公开声明卧底数）
  - 白板（可选变体，§8）：不持有词，靠听发言编造一个词，属于平民阵营
- **分配纪律**：主持人**私聊**逐人发放身份与词；群聊公屏只发「身份已发放完毕，游戏开始」类信号。**玩家泄露身份信息 → 按 §9 立即出局；主持人泄露 → 本局作废重开**（两案已定一，不并存）。
- **身份未知设计（v1.34 明示）**：发词**不带身份标签**——玩家初始不知道自己是平民还是卧底，身份靠词面推断 + 描述互证（演练局第 5 局验证：卧底不自知但模糊描述/投平民均客观成立）。全员按「假想自己是卧底」心态模糊描述，伪装博弈充分。
- **未收词纪律（v1.34）**：玩家未收到身份词 → **公屏声明并等待补发，禁止无词发言/瞎编/猜测描述**（演练局第 3 局测验验证）。

## 4. 每轮流程（状态机）

`发言 → 投票 → 淘汰 → 判定`，循环至终局。（v1.32 苍蓝星口头变更：去掉发言后的讨论环节，描述后直接投票）

1. **发言**：主持人点名发言，**每轮发言顺序随机**——轮开始时公屏公布本轮顺序（随机排序，不固定；防位置规律/顺序信息泄露）。每人每轮 1 条主发言（**≤50 字**）描述自己的词。**描述策略（苍蓝星指示，v1.34）**：① **模糊化**——假想自己是卧底，不暴露独特锚点；② **信息精简**——每句 **≤2 个信息点**、单维度（例：「和上下班有关的东西」；「地下+轨道+通勤+拥挤」= 信息过载，卧底一句即得推断依据；≤2 信息点与 ≤50 字并列，QA 量化建议 v1.35 采纳）。**禁止**：说出完整词本身、明显谐音、逐字拆解、翻译（例：不能说 apple）、拼音缩写（例：pg）、逐字复读他人本轮描述、复述主持人私聊内容。
2. **投票**：主持人宣布投票开始。玩家**私聊**按格式投票：`投票：<角色名>`（**用真名，不用编号**——私聊无需查映射表，少一步出错）。弃票 = `弃票`。全员弃票 → 无人出局，本轮结束，轮次照计，**计入无人出局计数**（与平票同规，连续 2 轮 → 决胜轮）。
3. **淘汰**：主持人公屏公布票数与出局者（**不公布投票人**——匿名票数是平民唯一推理依据，必须公开。出局者阵营不另行宣布：终局判定本身即揭示——终局=出局者为卧底、游戏继续=出局者为平民）。
   - 最高票唯一 → 该玩家出局；若出局者为**卧底** → 进入**猜词环节**（§5）：卧底 1 次机会私聊猜平民词（须完整词、禁止模糊答案，限时 5 分钟，超时 = 猜错）→ 猜对 → 卧底胜（终局）；猜错 → 平民胜（终局）。**猜词环节仅限被投票出局之卧底（v1.34：违规/判负/失联出局不适用**——防「违规低成本反转」，演练局第 3 局 QA 建议 + Dev 口径）。**猜词胜利仅限第 1 轮（v1.35 苍蓝星指示）：第 1 轮被投出的卧底可猜词翻盘；第 2 轮及以后被投出 → 禁止猜词胜利，直接平民胜**（后期多轮描述信息充分，卧底猜词命中过高失悬念——演练局 3/3 猜词翻盘均后期轮次）。若出局者为平民/白板 → 游戏继续
   - 最高票并列（**含全员各 1 票、无人最高的情况**，如 4 人局 1v1v1v1）→ 本轮无人出局，直接进入下一轮（不设重投，减少主持人工量）
   - **连续 2 轮无人出局 → 第 3 轮为决胜轮**（无人出局计数：平票或全员弃票均 +1，任一轮有人出局立即清零，「连续」以清零后重新起算）：每人 1 句最终陈词（≤50 字）+ 全员强制投票（**无弃票选项**；超时未投 = 无效票；**投票范围为全部存活玩家自由投**——陈词后信息更新，允许重新判断）→ 仍平票 **或全员无效票** → 裁判在**最高票并列者中**随机裁定 1 人出局（无有效票时并列者 = 全部存活玩家；裁定不超出并列者集合；抽签/掷骰——裁判是发词人必知身份，裁定必须中立，不得利用已知身份）
   - **存活玩家数降至 2 → 立即按 §5 终局判定，不再进入下一轮投票**（封死「剩 2 人互投平票」死局）
4. **判定**：按 §5 检查胜负；未终局则进入下一轮。

## 5. 胜负判定（互斥穷尽）

每轮淘汰后**只判一次**，两种胜利互斥：

- **平民胜**：卧底被投出且**猜词失败**（猜错平民词或超时未猜，§4.3 猜词环节）；**第 2 轮及以后被投出的卧底 → 直接平民胜（无猜词环节，v1.35）**。
- **卧底胜**（满足任一）：
  - 卧底被投出后**猜词成功**（猜对平民词，即终局）
  - 存活玩家数**降至 2**（无论何时、无论何阶段）且仍有卧底存活 → 立即终局判定，不再进入下一轮投票
- **继续**：未满足上述任一 → 进入下一轮。

**有界性保证**（无死局）：每轮淘汰或平票推进（平票不淘汰但轮次照计），连续 2 轮无人出局则第 3 轮为决胜轮（强制投票，仍平由裁判裁定出局）；存活数降至 2 即终局——淘汰必然持续发生，N 人局最多淘汰 N-2 次必到 2 人终局（4 人局最多错投 2 次即触发卧底胜，无需额外轮数上限）。

- 开局配置错误（如无卧底）→ 本局作废重开。

## 6. 主持人职责（苍蓝星操作卡——照做，不临场发挥）

**开局**
1. 选词对（§11），确定卧底数（4 人局 = 1）
2. **公屏**发开局声明（词对不出现）：卧底数 X（发言顺序每轮随机，轮开始时公布）
3. **私聊**每位玩家发：「你的词是：<词>，请回复确认」（发词**不带身份标签**——身份未知设计，§3）
4. 收齐全部确认 → **公屏**发：「身份已发放完毕，游戏开始」——**开局前置校验（v1.34）：未收齐全部确认不得宣布开始，描述不启动**（演练局第 3 局验证）

**信号链路（User 确认，2026-08 定稿）**：

1. **公屏信号/公告统一由 PM 代发**：苍蓝星私聊 PM 每步公屏内容（启动命令、点名顺序、投票开始/截止、票数公布、胜负判定），PM 整理为标准信号格式后代发公屏（User 私聊用词不一定规范，PM 规范化整理——**只整理格式、不改语义、不改判**，判定权归苍蓝星）。**代发纪律（v1.34 强化，演练局第 5 局教训）**：代发内容 = **苍蓝星原话转述（规范化格式）**，**禁止附加代发者任何个人判断**——身份推测/胜负断言/票数推断/自评（如「我投对」）一律不得入播报；苍蓝星未言明者明示「待裁判原话」，不自行补充。**苍蓝星亦可直接公屏发出等效信号，两种通道等效、User 任选**（直发信号同样按信号纪律识别，不误判为违规）
2. **身份隔离**：终局前苍蓝星私聊 PM 的内容**不得含词对/身份/票型**（PM 仍是玩家，公平性不破）；**终局公布词对与身份表可经 PM 代发**（比赛已结束，无信息优势）。**公屏禁词面/身份（v1.34 强化，qq 事件教训）**：PM 公屏信号与流程协调消息（含发词进度汇报）一律不得带任何词面/身份信息
3. **轮次开启信号例外**：「游戏轮次 = 群聊讨论轮次」依赖 User Persona 消息开启新轮——**每轮第一条「第 N 轮开始」由苍蓝星亲发**（一轮一条、负担最小；不生效则走预案 B，§7）；其余信号一律 PM 代发
4. **确认回执**：苍蓝星私聊 PM 后，**PM 私聊回复「收到」确认**，苍蓝星收到回执再推进下一步（防私聊遗漏）
5. **玩家识别规则**：玩家仅响应 `裁判：请 <角色名> 发言` 点名句式；**信号来源（PM 代发或苍蓝星亲发）不影响响应规则**；信号消息不参与违规判定

私聊发词/收票仍归苍蓝星（不进群聊、不经 PM）——PM 不涉及身份知情，继续当玩家；**若未来代发范围扩至身份/投票（终局公布除外）→ PM 退玩家池（降 3 人局）或仅公屏代发**（既定边界）。

**信号格式（统一「裁判：」前缀版）**：信号统一以 **「裁判：」开头**（纯汉字、零输入负担；发言内容出现「投票开始」「第 N 轮」等字样时不会被误判为信号，AI 识别零歧义），固定短语保留为内容约定（双保险）：
- **启动命令**：`裁判：谁是卧底 开局：卧底数 X｜词库编号 N`（PM 代发；苍蓝星私聊拟稿无需任何格式；指令仅含公屏安全信息——词对/身份仍由苍蓝星私发各玩家，PM 代发不多知信息、公平性不破；发言顺序每轮随机，轮开始时公屏公布）
- **阶段信号**：`裁判：第 N 轮开始`、`裁判：投票开始`、`裁判：投票截止`、`裁判：决胜轮`、`裁判：本局结束`
- **点名指令**：`裁判：请 <角色名> 发言`

**玩家响应纪律**：**玩家仅当消息点名自己才回复**（被点名时发言/投票）；主持链路信号消息**只读不回复**；**公屏禁止「收到」「明白」类确认消息**（防额度空耗），私聊确认不受限；信号消息**不参与违规判定**。

**每轮**
1. **公屏**点名玩家逐一发言（每人 ≤50 字，收 1 条再点下一位）
2. **公屏**发：「投票开始，私聊发 投票：<角色名> 或 弃票」（无讨论环节，描述完成后直接投票）
3. **私聊**收票：等满全部存活玩家，或触发 §10 异常预案
4. **公屏**公布票数与出局者（不公布投票人）；平票按 §4.3 处理
5. **判定**：若出局者为**卧底**且为**第 1 轮**被投出 → **执行猜词环节**（§4.3：私聊卧底猜平民词 1 次，限时 5 分钟，超时=猜错）→ 猜对=卧底胜 / 猜错=平民胜，即终局；**第 2 轮及以后卧底被投出 → 直接平民胜（无猜词，v1.35）**；若出局者为平民/白板 → 按 §5 判定（继续，或人数降至 2 立即终局）。**判定播报（v1.34）**：裁判判定原话完整给出（出局者身份 + 胜负方 + 分支依据，如「QA 出局（平民）→ 降至 2 → 卧底胜」），防简写/代发误读；**发词记录保留备查**（定案以发词记录为准）
6. 终局 → 公屏宣布胜负 + 公布词对与身份表；未终局 → 进入下一轮

每阶段**等什么**：等满该阶段应收到内容，或触发 §10 超时兜底；**怎么判**：一律按 §5/§9，不自由裁量。

**时限**：描述阶段默认 **10 分钟**、投票阶段默认 **5 分钟**（宣布投票开始后计时），**均须在轮开始时公屏宣布、中途不得更改**（防不公平）；超时未响应 = 该阶段缺描述/弃票，按 §10 异常预案处理。

**裁判中立原则**：全程裁判只做「发信号 / 等响应 / 公布结果」，不替玩家做任何决策（含平票随机裁定——用抽签/掷骰，不得利用已知身份）。

## 7. PiTavern 机制适配

- **双通道**：发言/拉票/盘问 = 群聊公屏（tavern_speak）；身份/投票 = 各角色与主持人的私聊 session
- **点名制**：主持人点名才发言，未点名不发言（防抢话）；同一轮内不插话
- **上限对齐**：**所有公屏游戏发言统一 ≤50 字/条**（每人每轮 1 条主发言），裁判按汉字计数，零歧义
- **轮次对齐**：**游戏轮次 = 群聊讨论轮次**——每游戏轮开始时，**主持人（苍蓝星）亲发一条「裁判：第 N 轮开始」信号消息开启新讨论轮次**（§6 第 3 点），发言额度自动重置（当前群聊 Round 上限 100，一局 3–5 轮 ≈45–60 条公开消息，单轮可容纳；对齐后多轮不耗尽单轮额度，机制零改动）。**⚠ 机制依赖（演练局第一实测项）**：文档背书 = terminology.md（讨论轮次由 User Persona 消息开启，roundMaxMessages 每轮新建时继承，额度随新轮重置属设计行为）；演练局开局实测确认，**预案 B**（不生效则整局控制在单轮 100 条内）与主案都保留

## 8. 可选变体（v1 默认全部关闭，主持人开局前声明启用）

- **白板位**：主持人指定 1 名玩家为白板（不拿词），发言时需编造一个词；被投出局按平民出局处理。建议 5 人及以上局启用（4 人局保持简单）
- **轮数上限**：主持人开局声明 M 轮后卧底仍未全出 → 卧底胜（标准规则靠「剩 2 人」兑底已无死局，此变体仅用于限定局时）

## 9. 违规与仲裁

**违规形态**（由裁判按「明显可辨识」裁量，单字出现不判违规——例：词=「分支」时描述里「支持」「分子」不误杀）：

1. 完整词本身
2. 明显谐音（例：平果 / 苹菓）
3. 逐字拆解（含拼音缩写，例：pg）
4. **英文翻译**（例：「分支」不能说 branch——翻译是最高效的泄词方式，不随收窄取消）
5. 逐字复读他人本轮描述（AI 复读风险）

**判罚**：首次违规 → 该发言作废 + 警告（可重说 1 条）；**再犯 → 该发言作废并重说**；同一玩家累计 3 次违规 → 判负出局。**泄身份（明确说出自己的词，含「我的词是 X」句式）→ 立即出局**；仅单说完整词（未指向自己）按违规形态 1 处理。**发言语境同规，无豁免**（描述/拉票时说出完整词同样判违规）。

**其他**：
- 主持人私聊泄露 → 本局作废
- 超条数/超字数 → 超限发言不计入，主持人提醒
- 投票结果公布前泄票型 → 该票作废
- 发言顺序：未点名抢先发言 → 该条不计入，主持人重新点名
- **广播延迟免责（v1.34，演练局系统性现象）**：信号（点名/叫停/投票开始等）存在到达延迟（PiTavern 环境特性），**因延迟导致的发言时序异常不计违规**——玩家以自己队列中最后到达的信号为准；仅明知信号已到仍违犯按 §9 处理（裁判按双方队列核对信号到达与发言时刻先后）
- **裁判仲裁结果公屏宣布并记录，不可上诉**

## 10. 异常预案（成员掉线/失联）

**双轨判别（写死，不得混用）**：

- **超时**（session 在线、时限内未响应）：本轮缺描述/弃票（温和兜底，防「只是慢」被误杀）；**连续 2 个描述轮未发言 → 裁判判负出局**（视同被投票出局仅用于 §5 终局判定，**不含猜词环节**——v1.34 限缩，演练局第 3 局 QA 建议 + Dev 口径）
- **失联**（session 断开 / 玩家明确声明失联）：**立即出局**，局继续、降级推进（4 人局失联 1 人自动降为 3 人局，胜负判定规则不变），不重开、不留悬挂
- **判别规则**：失联须主持人确认——**操作判据 = 该角色 pi session 实际不可达（终端可见进程断开/崩溃）或玩家私聊明确声明失联**；仅「时限内未回消息」一律按超时处理，**不得升级为失联**；主持人无法确认时按超时走
- **失联出局语义**：复用「判负视同被投出」——失联者 = 卧底 → 平民胜（终局）；= 平民 → 降级继续，并正常触发「人数降至 2 瞬间终局」判定；不留第三种分支

- **主持人失联**：本局**挂起**，等待主持人回归后从挂起点继续；回归后公屏声明「本局恢复，从第 X 轮继续」
- **失联玩家回归**：挂起中回归 → 恢复其发言权；已判出局 → 观战，不再参玩
- 任何时刻主持人掉线且无法回归 → 本局作废，由新主持人重新开局

## 11. 词库（主持人可自行扩充）

**词对可区分性要求**：词对须过可区分性检验（描述时能区分、不能一句话混过去）；**演练局逐对实测，误杀率高的词对移出词库**。
