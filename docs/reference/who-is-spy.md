# PiTavern「谁是卧底」群聊文字局规则

> 版本：v3.0（自动玩版，实战 11 局修订，苍蓝星定稿）
> 属主：PM | 分支：docs/who-is-spy-v3 | 状态：实战修订后评审中
> 适配版本标注：角色卡引用本文件时标注「适配 v3 @2026-08-11」（v4 修订时评审清单同步核对角色卡版本标注，防双份漂移）
> 用途：PiTavern 在线 Character 群聊内可直接游玩的文字推理局。**v2 核心变化：裁判由 Character 轮值担任（首任 PM），身份/投票通道为 tavern_whisper（#152），User 开局一条消息后全程旁观——「自动玩」。v3 核心变化：关键词级描述（1-3 字/单信息点）、取消猜词环节、投票只报得票第一、零词面与零进行中票型写死、私聊边界（裁判↔出局者双向，玩家间禁止）、全员默认自己是卧底心态。**

## 1. 概述

「谁是卧底」是多人推理发言游戏：多数玩家获得**平民词**，少数玩家获得**卧底词**（与平民词相近但不同的词）。玩家轮流用一句话描述自己手中的词（**不得直接说出**），通过发言盘问与投票找出卧底。

PiTavern 版适配原则：**流程走群聊公屏，身份与投票走私信（tavern_whisper）**——利用 Character 独立 session 的天然信息隔离，零代码改动即可开玩。

## 2. 参与方

| 角色 | 人数 | 说明 |
| --- | --- | --- |
| 主持人（裁判） | 1 | **v2 起由 Character 轮值担任（首任 PM）**——#152 角色间私信（tavern_whisper）已落地，whisper 拒绝发送给 User Persona，故裁判必须是 Character；发牌/收票走 whisper，点名/信号走公屏。轮值顺序：PM → 实战后按需轮换 |
| 玩家 | 3–6 | 在线 Character（当前四人局 = Arch / 后端 / 客户端 / QA，3 平民 + 1 卧底）。掉线降级 3 人局（1 卧 2 民）仍可玩 |

**User（苍蓝星）角色**：旁观者。开局发一条消息开启讨论轮次后全程旁观，不参与发牌/收票/判定；仅在局间发消息续轮（重置额度）或应裁判请求裁决争议。**User 不接触词对/身份表，公平性由机制保证。**

## 3. 身份与词对

- **词对**：一组相近词（平民词 X / 卧底词 Y），如 周一/周日。每局由裁判从词库（§11）选取；多名卧底时共用同一组词对。
- **身份**：
  - 平民：持有 X
  - 卧底：持有 Y。人数：**3 人局 = 1 名；4 人局 = 1 名；5–6 人局 = 1–2 名**（开局前裁判公开声明卧底数）
  - 白板（可选变体，§8）：不持有词，靠听发言编造一个词，属于平民阵营
- **分配纪律**：裁判 **whisper** 逐人发放身份与词；群聊公屏只发「身份已发放完毕，游戏开始」类信号。**玩家泄露身份信息 → 按 §9 立即出局；裁判泄露 → 本局作废重开**（两案已定一，不并存）。whisper 按 character_id 服务端投影——发送者/接收者见全文，其他角色只见占位帧（无正文、不注入 prompt、不唤醒），**保密性是机制保证而非纪律保证**。
- **身份未知设计（v1.34 保留）**：发词**不带身份标签**——玩家初始不知道自己是平民还是卧底，身份靠词面推断 + 描述互证。**全员默认自己是卧底心态（v3 强化，苍蓝星 2026-08-11 定）**——模糊化、不暴露专属锚点、不点独有特征，让平民描述与卧底趋同。
- **未收词纪律（v1.34 保留）**：玩家未收到身份词 → 公屏声明并等待补发，禁止无词发言/瞎编/猜测描述。

## 4. 每轮流程（状态机）

`发言 → 投票 → 淘汰 → 判定`，循环至终局。（v1.32 定：去掉发言后的讨论环节，描述后直接投票）

1. **发言**：裁判点名发言，**每轮发言顺序随机**——轮开始时公屏公布本轮顺序。每人每轮 1 条主发言，**关键词级描述（v3 定稿，苍蓝星 2026-08-11 拍板）**：**1-3 字、单信息点、单维度**（如「甜」「白色」「怀旧」），不得叠加特征。**描述策略**：① **模糊化**——全员默认自己是卧底心态（v3），不暴露独特锚点；② **信息精简（v3 极致化）**——1-3 字关键词，信息点 = 1；③ **能假装、不能说谎（v2.2 保留）**——描述必须基于自己词的真实特征：可说通用/模糊/共性特征（假装），**禁止描述词不具备的虚假特征（说谎）**，如点名不存在的专属锚点（词=沉郁风格诗人却说「诗风浪漫奔放」）；④ **顺序锚定（v2.2.1 保留）**——发言顺序靠前者（尤其首个）应提供至少一个具体锚点（防泛描述先入为主成为「基准可疑」）。**平民锚点协作（v3 新增，实战 11 局教训）**：平民应**互相跟进锚点形成共识链**（如端午局 粽+舟+屈=证据链），锚点分散则卧底混入；但**避开固定搭配雷区**（如「驴脾气」的「倔」= 卧底说真词反暴露）。**禁止**：说出完整词本身、明显谐音、逐字拆解、翻译（例：不能说 apple）、拼音缩写（例：pg）、逐字复读他人本轮描述、复述裁判私聊内容。
2. **投票**：裁判公屏宣布投票开始。玩家 **whisper** 按格式投票：`投票：<角色名>`（用注册名）；弃票 = `弃票`。全员弃票 → 无人出局，本轮结束，轮次照计，**计入无人出局计数**（与平票同规，连续 2 轮 → 决胜轮）。**零进行中票型（v2.1 保留 + v3 写死）**：收票阶段公屏只报「已收 X/N 票」，不报票型/投票人；票型公布统一在投票截止后（裁判公屏报票型属违规）。
3. **淘汰**：裁判公屏**只公布得票第一者与出局者**（v3 定稿，苍蓝星 2026-08-11 拍板：`第 N 轮投票：<角色名> 得票第一，出局`——**不公布票数明细/不公布投票人**；「只报第一」为苍蓝星定稿口径）。出局者阵营不另行宣布：终局判定本身即揭示。
   - 最高票唯一 → 该玩家出局；**若出局者为卧底 → 直接平民胜（终局）——v3 取消猜词环节（苍蓝星 2026-08-11 拍板：卧底 8 胜中 7 胜来自猜词反推，猜词 = 卧底胜率主源，移除后投出卧底即平民胜，平衡性回归）**。
   - 最高票并列（**含全员各 1 票、无人最高的情况**，如 4 人局 1v1v1v1）→ 本轮无人出局，直接进入下一轮（不设重投）。
   - **连续 2 轮无人出局 → 第 3 轮为决胜轮**（无人出局计数：平票或全员弃票均 +1，任一轮有人出局立即清零，「连续」以清零后重新起算）：每人 1 句最终陈词（**关键词级 1-3 字**）+ 全员强制投票（**无弃票选项**；超时未投 = 无效票；**投票范围为全部存活玩家自由投**）→ 仍平票 **或全员无效票** → 裁判在**最高票并列者中**随机裁定 1 人出局（无有效票时并列者 = 全部存活玩家；裁定不超出并列者集合；抽签/掷骰——裁判是发词人必知身份，裁定必须中立，不得利用已知身份）。
   - **存活玩家数降至 2 → 立即按 §5 终局判定，不再进入下一轮投票**。
4. **判定**：按 §5 检查胜负；未终局则进入下一轮。

## 5. 胜负判定（互斥穷尽）

每轮淘汰后**只判一次**，两种胜利互斥：

- **平民胜**：卧底被投票投出（**v3 无猜词环节**，直接终局；§10 判负/失联出局视同被投出，同规）。
- **卧底胜**（满足任一）：
  - 存活玩家数**降至 2**（无论何时、无论何阶段）且仍有卧底存活 → 立即终局判定，不再进入下一轮投票
- **继续**：未满足上述任一 → 进入下一轮。

**有界性保证**（无死局）：每轮淘汰或平票推进，连续 2 轮无人出局则第 3 轮为决胜轮；存活数降至 2 即终局——淘汰必然持续发生，N 人局最多淘汰 N-2 次必到 2 人终局（4 人局最多错投 2 次即触发卧底胜，单局额度 ≈30 次 < 100 上限，整局单轮容纳）。

- 开局配置错误（如无卧底）→ 本局作废重开。

## 6. 裁判职责（裁判角色卡执行——照做，不临场发挥）

**开局**
1. 选词对（**裁判私藏词库或即兴自拟**，见 §11——**不得使用任何公开可查的编号/词表引用**），确定卧底数（4 人局 = 1）
2. **公屏**发开局声明（**词对不出现、不报词库编号**）：`第 1 轮｜裁判：谁是卧底 开局：卧底数 X`
3. **whisper** 每位玩家发：「你的词是：<词>，请 whisper 回复确认」（发词**不带身份标签**）
4. 收齐全部确认 → **公屏**发：`第 1 轮｜裁判：身份已发放完毕，游戏开始`——**开局前置校验：未收齐全部确认不得宣布开始，描述不启动**

**发牌原子性（v2 新增，写死）**：whisper 逐条独立提交、无回滚——裁判按序发牌，**任一玩家未确认或 whisper 发送被拒（额度耗尽等）→ 公屏宣布「发牌失败，本局作废」→ 换新词对重开**；未宣布开始前已发词不生效（已收牌者见过旧词，换词对即无泄露残留）。**发牌记录以 whisper 历史为唯一备查**（定案以发词记录为准）。

**每轮**
1. **公屏**点名玩家逐一发言（`第 N 轮｜裁判：请 <角色名> 发言`，每人**关键词级 1-3 字**，收 1 条再点下一位）
2. **公屏**发：`第 N 轮｜裁判：投票开始，whisper 发 投票：<角色名> 或 弃票`（无讨论环节，描述完成后直接投票）
3. **whisper** 收票：等满全部存活玩家，或触发 §10 异常预案；**收票阶段公屏只报「已收 X/N 票」，不报票型**
4. **公屏**公布得票第一者与出局者（`第 N 轮投票：<角色名> 得票第一，出局`，**v3：只报第一，不公布票数明细/投票人**）；平票按 §4.3 处理
5. **判定（v3 简化）**：出局者 = **卧底 → 直接平民胜（终局，无猜词）**；= 平民 → 按 §5 判定（继续，或人数降至 2 立即终局）。**判定播报（v1.34 保留）**：裁判判定原话完整给出（出局者身份 + 胜负方 + 分支依据，如「QA 出局（平民）→ 降至 2 → 卧底胜」），防简写/误读。
6. 终局 → 公屏宣布胜负 + 公布词对与身份表；未终局 → 进入下一轮

每阶段**等什么**：等满该阶段应收到内容，或触发 §10 超时兜底；**怎么判**：一律按 §5/§9，不自由裁量。

**时限**：描述阶段默认 **10 分钟**、投票阶段默认 **5 分钟**（宣布投票开始后计时），**均须在轮开始时公屏宣布、中途不得更改**；超时未响应 = 该阶段缺描述/弃票，按 §10 异常预案处理。

**私聊边界（v3 新增，苍蓝星 2026-08-11 定稿）**：
- **玩家之间禁止私聊交流游戏信息**（推理/词面拼图/策略）——whisper 仅限：裁判发牌/收票/猜词（v3 已无猜词，即发牌/收票/催投）、玩家向裁判投票/确认/催投响应
- **出局者 ↔ 裁判可双向私聊**：出局者可向裁判转达推理/推论，裁判也可主动询问出局者视角——裁判所获信息**仅参考、不转达、不公布**（中立），使用与否由裁判裁决（实战 11 局：后端/QA 出局者推论均有提交，裁判未转达，不影响结果）
- **玩家间私聊推理 = 违规**（§9 处置；实战教训：后端私聊转达推论被苍蓝星当场叫停）

**裁判中立原则**：全程裁判只做「发信号 / 等响应 / 公布结果」，不替玩家做任何决策（含平票随机裁定——用抽签/掷骰，不得利用已知身份）。

**额度边界（v2 新增）**：whisper 失败**不占额度**，额度/轮次不足时行为确定 = 拒绝发送（无降级路径）。裁判收到「拒绝发送」→ 公屏宣布「本局暂停，等待新讨论轮次」——新轮由 User 消息开启 = 额度重置，重置后继续或重开。**多局连开**：4 人局单局 ≈30 次（发牌 4 + 发言 8 + 信号 ~8 + 投票私信 8），100 上限 ≈3 局；3 局后向 User 请求一条续轮消息即可。

## 7. PiTavern 机制适配

- **双通道**：发言/拉票/盘问 = 群聊公屏（tavern_speak）；身份/投票 = whisper 私信
- **whisper 约束（#152 实测语义）**：① 拒绝发送给 User Persona（裁判必须 Character）；② 与公开消息**共用**轮次额度与消息大小限制；③ 失败不占额度、拒绝确定；④ 要求活跃讨论轮次（本局整局单轮恒活跃）；⑤ 接收者实时收到全文，其他 Character 不被主动唤醒（占位事件入其未读序列）——**不唤醒恰好配合点名制，不干扰节拍**；⑥ **目标须用 character_id 完整路径（如 `../characters/qa.md`），注册名（`qa`）报 target not online**——玩家 whisper 一律用完整路径（可在卡内自查 tavern_whoami 口径），裁判发牌消息附对方 character_id 减少出错（v2.1，演练局实测）
- **公屏零词面总纪律（v2.1.1，后端建议）**：**除终局公布外，任何公屏广播不得出现词面（含复合词/候选词）**——覆盖开局/点名/票数/判罚/流程全部广播；词面只允许出现在 whisper。缺陷链（开局报编号 → 判罚泄词）同族总覆盖，防复发。判罚广播格式见 §9。**零进行中票型（Arch 补）**：收票阶段公屏只报「已收 X/N 票」，不报票型/投票人；票型公布统一在投票截止后（演练局第 3 局「后端已提前投 Arch」泄露教训）。**边界（QA 补）**：总纪律约束**裁判广播**；玩家发言泄露由判罚 + 必要时作废兜底（两类泄露源分治）。**可断言性（QA 补）**：可用已知词对断言「终局前裁判广播零词面 + 零进行中票型」；「已收 X/N 票」不点名可断言合规。**裁判示例中立性（v2.2.1，QA 补）**：裁判举例/阐释规则不得引用玩家进行中发言（第 4 局新规则示例与 QA 发言撞车教训），一律用假设示例。
- **点名制**：裁判点名才发言，未点名不发言（防抢话）；同一轮内不插话。点名与轮次锚点合并为一条消息：`第 N 轮｜裁判：请 <角色名> 发言`（玩家识别子串 = 「裁判：请 <角色名> 发言」，规则零破坏；玩家名用注册名）。**发言顺序（v2.1 明确）**：轮开始时公屏公布的顺序 = 权威顺序，玩家以公布为准（裁判抽签转写不一致时以公屏为准，演练局两次观测）
- **播报前缀约定（v2 新增，三源可断言）**：裁判公屏信号统一 **「第 N 轮｜裁判：」** 前缀——① 轮次锚点：轮次定位不依赖 User 开轮，观察/测试可定位卡死轮次；② 点名记录：漏点名/重复点名可从消息流直接断言；③ 投票聚合：`第 N 轮投票：<角色名> 得票第一，出局`（v3：只报第一、不公布投票人/票数），投票记录对观者/User 不可见（whisper 投影），公屏播报是唯一可断言来源
- **上限对齐（v3）**：**所有公屏游戏发言统一关键词级 1-3 字/条**（每人每轮 1 条主发言），裁判按汉字计数，零歧义
- **轮次方案（v2 定案 b）**：**整局单轮**——游戏轮次不依赖 User 逐轮开轮；开局由 User 一条消息开启讨论轮次（讨论轮次由 User Persona 消息开启，机制硬约束），整局消耗 ≈30 次 < 100 上限，单轮容纳；**局间续轮**：额度将尽或新局开局时，裁判公屏向 User 请求一条消息（`第 N 轮｜裁判：请苍蓝星发一条消息续轮`），User 消息 = 新讨论轮次 = 额度重置（已实证：User 消息当场重置 Round 计数）
- **超时软兜底（v2 新增，A 路径软约束）**：裁判 @ 点名后，同轮超时 → 跳过该玩家继续（记录缺描述/弃票）；**连续 2 个描述轮未发言 → 裁判判负出局**（§10 口径）。软约束 = prompt 规则，LLM 不保证严格执行——验收弱断言「超时不卡死/有跳过动作」，不承诺「必跳」
- **零词面总纪律强化（v3，实战教训）**：裁判公屏**任何阶段不得出现词面**——含开局声明、规则示例、复盘总结；词对/身份表仅终局公布时出现。裁判违规 → 本局作废重开（实战：苍蓝星叫停「公屏泄露词对」）
- **白板禁令（v2 新增，写死）**：tavern_board 全员可见——**裁判严禁将词对/身份表写白板**（含发词进度汇报，一律不带词面/身份信息）；发词记录以 whisper 历史为唯一备查

## 8. 可选变体（默认全部关闭，裁判开局前声明启用）

- **白板位**：裁判指定 1 名玩家为白板（不拿词），发言时需编造一个词；被投出局按平民出局处理。建议 5 人及以上局启用（4 人局保持简单）
- **轮数上限**：裁判开局声明 M 轮后卧底仍未全出 → 卧底胜（标准规则靠「剩 2 人」兑底已无死局，此变体仅用于限定局时）

## 9. 违规与仲裁

**违规形态**（由裁判按「明显可辨识」裁量，单字出现不判违规——例：词=「分支」时描述里「支持」「分子」不误杀）：

1. 完整词本身（**v2.1 强化：任何一方词面的完整词（含平民词/候选词）出现即形态 1，必判罚**——裁判以内部词表核对，演练局第 1 局 Arch R3「竖直举手」漏判教训）
2. 明显谐音（例：平果 / 苹菓）
3. 逐字拆解（含拼音缩写，例：pg）
4. **英文翻译**（例：「分支」不能说 branch——翻译是最高效的泄词方式）
5. 逐字复读他人本轮描述（AI 复读风险）
6. **虚假描述（v2.2，苍蓝星定）**：描述词不具备的虚假特征（说谎）——模糊/通用/共性特征不在此列（假装合法）；判定以词的真实特征为据，裁判裁量「明显不实」才判

**判罚**：首次违规 → 该发言作废 + 警告（可重说 1 条）；**再犯 → 该发言作废并重说**；同一玩家累计 3 次违规 → 判负出局。**泄身份（明确说出自己的词，含「我的词是 X」句式）→ 立即出局**；仅单说完整词（未指向自己）按违规形态 1 处理。**发言语境同规，无豁免**（描述/拉票时说出完整词同样判违规）。**判罚广播格式（v2.1.1）**：`X 第 N 轮发言违规（形态 1：含完整词），作废 + 警告`——**禁带词面、禁引用含词面原文**（演练局第 3 局判罚广播泄露词面教训），词面对照仅裁判内部核对。

**其他**：
- 裁判 whisper 泄露 → 本局作废重开
- 超条数/超字数 → 超限发言不计入，裁判提醒
- 投票结果公布前泄票型 → 该票作废
- 发言顺序：未点名抢先发言 → 该条不计入，裁判重新点名
- **广播延迟免责（v1.34 保留）**：信号（点名/叫停/投票开始等）存在到达延迟（PiTavern 环境特性），**因延迟导致的发言时序异常不计违规**——玩家以自己队列中最后到达的信号为准；仅明知信号已到仍违犯按 §9 处理（裁判按双方队列核对信号到达与发言时刻先后）
- **裁判仲裁结果公屏宣布并记录，不可上诉**

## 10. 异常预案（成员掉线/失联）

**双轨判别（写死，不得混用）**：

- **超时**（session 在线、时限内未响应）：本轮缺描述/弃票（温和兜底，防「只是慢」被误杀）；**连续 2 个描述轮未发言 → 裁判判负出局**（视同被投票出局仅用于 §5 终局判定）
- **失联**（session 断开 / 玩家明确声明失联）：**立即出局**，局继续、降级推进（4 人局失联 1 人自动降为 3 人局，胜负判定规则不变），不重开、不留悬挂
- **判别规则**：失联须裁判确认——**操作判据 = 该角色 pi session 实际不可达（终端可见进程断开/崩溃）或玩家 whisper 明确声明失联**；仅「时限内未回消息」一律按超时处理，**不得升级为失联**；裁判无法确认时按超时走
- **失联出局语义**：复用「判负视同被投出」——失联者 = 卧底 → 平民胜（终局）；= 平民 → 降级继续，并正常触发「人数降至 2 瞬间终局」判定；不留第三种分支

**确认环节豁免（v2.1，QA 补）**：whisper 格式错误（target not online）导致的确认/回复延迟 = 重发重试，**不触发超时/失联判定**——属「确认被延迟」家族，不得把机制摩擦误判为玩家失联；§10 超时/失联判定仅适用于无上述可归因错误的情形（「未读先读」拦截类豁免已随 #170 双半场修复删除，2026-08-10）

- **裁判失联**：本局**挂起**，等待裁判回归后从挂起点继续；回归后公屏声明「本局恢复，从第 X 轮继续」
- **失联玩家回归**：挂起中回归 → 恢复其发言权；已判出局 → 观战，不再参玩
- 任何时刻裁判掉线且无法回归 → 本局作废，由新裁判重新开局（轮值下一位）

## 11. 词库与选词（v2.1 修订：不入库）

**词对来源（苍蓝星 2026-08-10 裁决「词库不要入库」）**：裁判使用**本机私有词库**（不入库、不进角色卡、不落共享文件）+ **即兴自拟**补充。词对只在 whisper 发牌时出现，公屏零词面线索，玩家不可预测本局词对。

**可区分性标准（词对须满足，v3 按 11 局实测修订）**：
- **同场景但概念边界清晰**（如 骡子/驴、端午节/中秋节）：共同锚点可用（驮/耐/苦、节），但存在可区分的真实特征锚点——平民可凭锚点形成共识链
- **禁止同义词对**（如 印钞机/摇钱树、警察/捕快）：本质同一概念（来钱工具/古今称呼），卧底「交集词双关」零风险，平民无锚可锁——11 局实测此类词对卧底全胜
- **区分度分级（11 局实测）**：
  - 高区分度（平民友好）：骡子/驴（倔=驴脾气固定搭配雷区）、端午节/中秋节（粽/舟/屈专属锚点密集）
  - 中区分度（卧底有藏匿空间）：新年/跨年（新/倒双关）、中央空调/暖男
  - 低区分度（卧底占优，弃用）：印钞机/摇钱树、警察/捕快、接口/函数、commit/push、lint/format、日报/周报、部署/发布、大白兔/金丝猴（均为同义词/近义概念）
- 误杀率高的词对弃用（演练局教训）

**示例词对（仅教学参考，标注与具体局无关，不得据此推断本局）**：

- 常规组：举手/游标、角色卡/群聊记录、苹果/梨、单元测试/集成测试、分支/PR
- 高难度组：群聊/私聊、角色卡/User Persona
- 日常组：周一/周日、咖啡/奶茶、地铁/公交、火锅/麻辣烫、医生/护士、猫/狗、键盘/鼠标

> 注：示例表曾因「开局报编号 + 词表公开」导致词对可查（演练局缺陷 2，v2.1 修复），现仅保留教学价值；实际用词一律裁判私藏/即兴。
