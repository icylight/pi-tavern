# ADR-0010：剧本驱动的 e2e 测试（对话记录即测试）

- 状态：已接受（2026-08-09 苍蓝星提出构想，五方共识）
- 背景：#152 PR #160 三轮 AI 评审暴露 acceptance 层欠账（RH3 挂账未关）；苍蓝星提出「统一对话记录 + 测试组件按对话记录跑（像剧本）」

## 背景

既有 acceptance 三层驱动（进程层 pi-process / 协议层 ws-helper / 数据层 JSONL fixture）各自为战，跨层场景需手写胶水；工具链（tavern_whisper/speak 注册→门禁→调用→文案）真实进程级测不到（RPC 模式无 LLM 输入通道）。苍蓝星指出方向性改进：以统一对话记录为单一事实源，测试组件按剧本驱动真实系统。

## 决策

1. **剧本 = 对话记录 + 期望断言**（单一事实源，格式 = JSONC——与 schema/*.jsonc 惯例一致，注释承载场景说明）：剧本条目 = 真实 entry 形状（sender/recipient/content/sequence/round，与协议/持久化同构）+ 元注解（act/expect/observer）。与 JSONL 同构 → 双向核对（跑完 diff 剧本 vs 真实记录即断言）。
2. **解释器边界**：剧本 → 通道映射（act:whisper → WS whisper 帧；act:speak → speak 帧；act:inject → JSONL append）→ 断言映射（observer:creator → creator-display 事件流；observer:角色 → WS 帧流；phase:resume → 重启后事件流）。解释器零业务逻辑（只做映射与对照，防二次漂移——ADR-0009 教训）；复杂时序断言走逃生舱 code hook，不强行 DSL 化。
3. **分层落地**：
   - 本轮（S）：协议直驱组件（ws-helper 通用发帧 + 连接工厂 + JSONL 生成器）+ 首部剧本 = RH3 验收断言（验收阻断与架构升级同时落地）
   - 0.4.0 收口（M）：完整剧本解释器 + 场景编排收敛（替代手写胶水）
   - backlog：既有 22 文件渐进改写（可选）、进程池复用（暂缓）、工具面测试通道（工具链膨胀后评估）
4. **acceptance 条目 ↔ 剧本文件一一对应**（规格即剧本，可审查可追溯）。
5. **一测试用例 = 一剧本，原子化**（苍蓝星 2026-08-09 指示）：scripts/<scenario>.jsonc 与测试用例同名 1:1；原子性三则 = 自管 setup/teardown（独立 mkdtemp + 独立进程组）/ 不依赖其他剧本遗留状态 / 单剧本可独立定向跑（与门禁显式定向纪律衔接）；选择性执行 = 按涉及面挑剧本跑，失败定位精确到剧本。

## 若不成立则失效（脆弱点声明）

- 若剧本 DSL 覆盖复杂时序导致解释器膨胀复制业务逻辑 → 决策 2 失效；判据：解释器中出现业务分支（非映射逻辑）。
- 若剧本与 JSONL 形状漂移（双向核对断链）→ 决策 1 失效；判据：剧本字段无法直接对照真实 entry。
- 若逃生舱滥用（剧本大量退化为代码钩子）→ 决策 1 的「规格即剧本」失效；判据：剧本文件中 code hook 占比 > 30%。

## 后果

- 正向：e2e 场景编写从写胶水变写剧本；新增功能场景 = 新增剧本；规格与测试同一载体。
- 负向：首轮需要 DSL/解释器基建投入（MVP 已由协议直驱组件承担，增量受控）。
